# Brand assets

These assets come from Tom Jagus’s personal brand-identity kit. Use the supplied files unchanged for this profile; do not recreate the wordmark, recolor its strokes, or distort the images.

- `banners/github.png`: supplied 1200 × 240 banner, displayed at the top of the profile README without cropping.
- `avatar.png`: original 1086 × 1448 illustrated avatar, for upload through GitHub’s profile settings. Review the square crop and circular preview before accepting it; no platform-specific crop is included.
